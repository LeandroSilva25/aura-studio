# Studio Aura — Landing (HTML/CSS/JS)

Landing page estática baseada no `prd_studio_aura.md` e no design system em `DESIGN.md`.

## Estrutura
- `src/index.html`
- `src/styles.css`
- `src/main.js`
- `src/assets/` (coloque seus arquivos aqui)
